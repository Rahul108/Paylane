# web

Customer portal, BFF, and test console for the Paylane platform.

## Features
- Next.js 14 App Router
- Server-side JWE signing/encryption to orchestrator
- Interactive test console for testing all payment journeys and edge scenarios
- Direct real-time tracking of journey steps and ledger state

## Running locally
```bash
npm run dev
```
Runs by default on port `3010`.
